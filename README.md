# Psychopharm Atlas

**精神药理图谱 | An evidence-traceable psychopharmacology knowledge base**

Psychopharm Atlas 是一个以精神药理学为核心的开放阅读型知识仓库，整理药物身份、分类、法域批准信息、临床证据与安全性资料。主药物档案用于快速了解药物是什么、适用范围如何、主要证据与风险在哪里。需要深入解释的药代、药效、剂型或临床争议，另见专题分析与原始来源。

项目以 WHO ATC/DDD 为基础分类索引，同时记录中国管制信息、不同法域的产品批准差异、临床证据与按使用场景的适宜度。评分不合并为单一总分，也不构成个体化用药建议。

## 收录范围

仓库目前包含 **384 份药物档案**，其中核心六个 ATC 组 280 份，跨组主题档案 104 份。核心目录依据 WHO ATC/DDD Index 2026，覆盖 294 个五级编码。并非每个编码都对应独立药物档案，未指明全部成分的复方分类代码也不会自动建立为具体药品。

## 阅读说明

1. 档案顶部的 `indexed`、`basic` 与 `reviewed` 表示证据核查完成度，不代表药物是否获批、是否仍在销售，也不代表临床推荐。
   - `indexed`：药物身份与分类已核实。
   - `basic`：已有可靠基础临床或安全信息，核心模块尚未完成系统核查。
   - `reviewed`：基本信息、适应范围、管制状态、关键临床证据、主要风险、重要相互作用与证据边界已按项目标准系统核查。
2. ATC 分类只说明药物在分类体系中的位置，不能单独证明适应证、疗效或监管批准。
3. 监管结论必须对应具体法域、产品、剂型与说明书版本。一个国家或数据库的检索结果不能直接代表全球批准状态。
4. 中国管制状态与药品上市批准是两项独立信息，应分别阅读。
5. DDD 是药物利用研究中的统计技术单位，不是处方剂量或个人用药建议。
