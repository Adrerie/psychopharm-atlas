# Psychopharm Atlas

**精神药理图谱 | An evidence-traceable psychopharmacology knowledge base**

Psychopharm Atlas 是一个以精神药理学（Psychopharmacology）为核心的开放阅读型知识仓库。项目整理精神科及相关神经系统药物的分类、分子作用机制、药代动力学、临床证据与安全性信息，重点解释药物为什么产生某些效应，以及现有证据能够支持怎样的结论。

本项目以药物通用名为基本条目，以 [WHO ATC/DDD](https://atcddd.fhi.no/atc_ddd_index/) 为基础分类索引，并同时保留作用机制、临床用途等交叉分类。ATC 分类不代表药物只能用于某种疾病，DDD 也不等于推荐或个体化用药剂量。

## 分析范围

- **分类与身份**：通用名、别名、ATC 编码、药物类别及不同地区的监管状态。
- **药效学（Pharmacodynamics）**：受体、转运体、酶等靶点，激动或拮抗等作用性质，以及研究条件。
- **药代动力学（Pharmacokinetics）**：吸收、分布、代谢、消除和具有临床意义的活性代谢物。
- **剂量与效应**：仅在有可靠证据时讨论剂量依赖关系，明确区分实验指标、受体占有率和临床观察。
- **临床证据**：区分获批适应证、指南建议、超说明书使用与尚处研究阶段的用途。
- **安全性与不确定性**：不良反应、相互作用、重要警告、证据局限及不同研究结论。

项目主要使用中文撰写，首次出现的专业术语附英文名称。内容将按具体药物逐步增加，不以尚未收录的条目声称目录完整。

## 核心原则

1. **结论可追溯**：每条实质性药理学或临床主张尽量对应到具体标签、指南或研究，并记录适用条件。
2. **机制不等于疗效**：体外受体亲和力不能直接推导人体中的受体占有率、实际疗效或安全性。
3. **区分信息层级**：监管批准、临床指南、随机试验、观察性研究、机制实验及个人经验分别标注。
4. **呈现不确定性**：对证据不足、结果矛盾或地区性差异作明确说明，不根据印象补全缺失数据。
