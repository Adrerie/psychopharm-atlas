# 恶性综合征与 5-羟色胺综合征｜两类标签风险为什么不能互推

> 配套主条目 [olanzapine](../drugs/olanzapine.md)、[haloperidol](../drugs/haloperidol.md)、[clozapine](../drugs/clozapine.md)、[valbenazine](../drugs/valbenazine.md)、[moclobemide](../drugs/moclobemide.md)、[clomipramine](../drugs/clomipramine.md)、[venlafaxine](../drugs/venlafaxine.md)、[tryptophan](../drugs/tryptophan.md)、[rasagiline](../drugs/rasagiline.md) ｜ 建立 2026-11-11  
> 本页只回答一个问题：恶性综合征（NMS）与 5-羟色胺综合征在各自主条目的标签里分别由什么药物触发、各自列出哪些症状，为什么两张症状清单有重叠但不能合成一个诊断或一个跨药风险排序。所有事实回各主条目与标签原文，不在本页重新计算。  
> 引用键与产品版本沿用各主条目 §11。

## 1. 问题与结论摘要

1. **触发药物不同**：NMS 出现在多巴胺阻断药与部分多巴胺能药物的撤药情境。5-羟色胺综合征出现在血清素能药物联用或过量。两类标签各自写明触发条件。
2. **症状有重叠**：NMS 标签写高热、肌强直、意识改变与自主神经不稳定，可伴 CK 升高、横纹肌溶解与急性肾衰。5-羟色胺综合征在一些标签里写意识模糊、发热、惊厥、共济失调、反射亢进、肌阵挛与腹泻。
3. **标签不是诊断标准**：标签给的是风险描述与症状清单，不是诊断标准。把两张清单重叠的部分合并，会制造一个标签并不支持的"血清素毒性"类别。
4. **处置方向不同**：NMS 的核心是停用致病药物与支持治疗，标签对再用药写明可复发。5-羟色胺综合征的核心是停用血清素能药物与支持治疗。两类都需识别共服药物。
5. **结论**：按触发药物类别分别记录，不把两类综合征合成一个跨药评分或一个"恶性综合征样表现"的通用条目。

## 2. NMS 侧的标签事实

- **奥氮平**：标签把 NMS 列为独立警告，含横纹肌溶解与急性肾衰竭报告。停药相关处置语句写在警告章内。
- **氟哌啶醇**：NMS 有复发记载，可伴 CPK 升高、横纹肌溶解与急性肾衰竭。
- **氯氮平**：黑框与警告章节含 NMS。标签在 NMS 条目中提到与包括锂在内的中枢活性药合用的报告。
- **缬苯那嗪**：标签写 NMS 可伴高热与肌强直、意识改变与自主神经不稳定，可伴 CK 升高与横纹肌溶解、急性肾衰，再用药可复发。
- **雷沙吉兰**：标签专列"戒断性高热与意识混乱"，指快速减量、停药或更改多巴胺能治疗可出现类神经阻滞剂恶性综合征症状复合体。这是撤药情境的 NMS 样表现。

NMS 的标签事实集中在两点：多巴胺阻断与撤药，以及 CK 升高与横纹肌溶解这一组并发症。

## 3. 5-羟色胺综合征侧的标签事实

- **吗氯贝胺**：标签把 5-羟色胺综合征列为 Rare，写明发生于与增强 5-羟色胺的药物合用时。标签列出的症状包括意识模糊、发热、惊厥、共济失调、反射亢进、肌阵挛与腹泻。禁忌清单含 SSRI／SNRI、三环类、曲普坦、哌替啶、曲马多、右美沙芬与利奈唑胺。
- **氯米帕明**：美国与英国文件都把 5-羟色胺综合征列为具名风险，触发组合包括 SSRI、SNRI、锂、曲马多与丁丙诺啡／阿片类。英国另列与抗精神病药／抗胆碱药合用时的高热。
- **文拉法辛**：美国标签 §5.2 点名曲普坦、三环类与阿片类，锂、丁螺环酮、安非他明、色氨酸与圣约翰草同样在列。英国文本把范围扩到芬太尼、他喷他多与曲马多，并单列"血清素综合征与恶性抗精神病药综合征样表现"。
- **色氨酸**：英国标签把 5-羟色胺能组合列为 5-羟色胺综合征风险，需要询问所有抗抑郁药与中枢抑制剂。
- **缬苯那嗪**：与 MAOI 合用时标签把血清素综合征风险列为需要处理的方向之一。

5-羟色胺综合征的标签事实集中在联用组合：MAOI、SSRI／SNRI、三环类、曲普坦、阿片类与色氨酸。

## 4. 重叠与不可合并之处

| 项目 | NMS 侧标签 | 5-羟色胺综合征侧标签 |
| --- | --- | --- |
| 触发 | 多巴胺阻断药，或停用多巴胺能药物 | 血清素能药物联用或过量 |
| 高热与肌强直 | 明确写出 | 明确写出 |
| 意识改变 | 明确写出 | 意识模糊 |
| 反射亢进、肌阵挛、共济失调、腹泻 | 标签未列为要点 | 吗氯贝胺标签明确列出 |
| CK 升高、横纹肌溶解、急性肾衰 | 多个标签明确写出 | 标签未列为要点 |
| 再用药复发 | 缬苯那嗪与氟哌啶醇标签写明 | 标签不作此表述 |

这张表只能说明两类标签的描述重心不同。不能由它推出诊断规则。也不能用一边的症状清单去筛查另一边。

## 5. 对档案写法的含义

- NMS 与 5-羟色胺综合征分别记录在各自的药物条目里，不合并成"血清素毒性"或"恶性综合征样表现"的通用条目。
- 触发药物类别写清楚：多巴胺阻断、撤药、血清素能联用。
- 标签症状清单照录，不补诊断标准，不写 "Hunter 标准" 等标签之外的判据。
- 跨药比较只放在本页这种同问题并列的位置。
